# Aesthetic Web Calculator 🧮

A clean, modern, and fully functional web-based calculator built using core web technologies. This project focuses on a smooth user interface, fundamental DOM manipulation, and handling arithmetic logic in plain JavaScript.

## 📸 Preview


## 🌟 Features

* **Basic Arithmetic:** Supports addition, subtraction, multiplication, and division.
* **Clean UI:** Soft pastel gradient background with distinct, easily readable buttons and hover states.
* **Quick Corrections:** Includes both "Clear All" (C) and "Backspace/Delete" (←) functionalities for easy editing.
* **Responsive Layout:** Neatly structured calculator body that stays centered and visually balanced.

## 🛠️ Tech Stack

* **HTML5:** Semantic structure for the calculator grid and display.
* **CSS3:** Custom styling, gradient backgrounds, border-radii, and button aesthetics.
* **JavaScript (Vanilla):** Event listeners, arithmetic logic, and dynamic DOM updates for the display screen.

## 🚀 Getting Started

Since this project uses basic web technologies, there is no need for complex build tools or package managers.

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/yourusername/aesthetic-calculator.git](https://github.com/yourusername/aesthetic-calculator.git)
    ```

2.  **Navigate to the project directory:**
    ```bash
    cd aesthetic-calculator
    ```

3.  **Run the project:**
    Simply open the `index.html` file in your favorite web browser. Alternatively, if you use VS Code, you can run it using the **Live Server** extension.

## 🧠 What I Learned

Building this project was a great way to solidify fundamental frontend concepts:
* Managing state (current input, previous input, selected operator) in plain JavaScript.
* Event handling and capturing user input from multiple buttons dynamically.
* Handling edge cases like stringing together multiple operations or preventing consecutive operators.
* Practicing CSS styling to create a polished, user-friendly interface.
